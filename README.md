BasebandForge: Demystifying the RF Physical Layer
This project is a ground-up Software Defined Radio (SDR) architecture built in Python. Instead of relying on black-box wrappers like GNU Radio, BasebandForge implements the mathematical core of telecommunications. It processes 240 MSPS composite baseband data, featuring a custom 255-tap FIR brick-wall filter, DPLL carrier recovery for 19kHz pilot tones, DSB-SC stereo matrixing, and differential BPSK decoding to extract Radio Data System (RDS) frames.
