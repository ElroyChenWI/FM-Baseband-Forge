## 🛠️ 極致細節：參數矩陣與物理原理

### 1. 射頻擷取與基頻轉換 (RF to Baseband)
*   **關鍵參數**：
    *   `FS_RF = 2,400,000 Hz`：RTL-SDR 的穩定點，高於 Nyquist 頻率 12 倍，確保抗混疊（Anti-aliasing）裕度。
    *   `DECIMATION = 10`：配合 `ftype='fir'`。這不僅是降頻，更是透過低通濾波提升了 **10dB 的處理增益**。
*   **演算細節**：`np.angle(iq[1:] * iq[:-1].conj())`
    *   **原理**：這是在運算複數向量的「相位導數」。透過點積共軛，將振幅資訊抹除，僅保留相位差 $\Delta\phi$。
    *   **Why？**：FM 的本質是頻率調變 $\omega(t) = d\phi/dt$。這行程式碼完美地實作了數位鑑頻器。

### 2. 立體聲分離矩陣 (Stereo Mastery)
*   **關鍵參數**：
    *   `FIR Taps = 255`：選用 255 階權重，旨在取得 80dB 以上的阻帶衰減（Stopband Attenuation），防止單聲道音訊干擾 RDS 數位資料。
    *   `Pilot BPF = [18.5k, 19.5k] Hz`：極窄帶設計，確保 19kHz 導頻的相位純淨度。
*   **演算細節**：`pilot_squared = pilot_tone ** 2`
    *   **原理**：利用三角恆等式 $\cos^2(\theta) = \frac{1 + \cos(2\theta)}{2}$。
    *   **Why？**：這就是在軟體中實作「倍頻鏡」。透過平方運算，我們從 19kHz 的能量中精確導出同步的 38kHz 副載波。

### 3. 去加重濾波 (De-emphasis)
*   **關鍵參數**：`τ = 50e-6` (50 微秒)。
*   **演算細節**：`alpha = 1 / (tau * fs + 1)`；`lfilter([alpha], [1, -(1 - alpha)], data)`
    *   **原理**：實作一個極具美感的數位 RC 單極點低通濾波器。
    *   **Why？**：補償發射端為了抗噪而預做的高頻強化。沒有這一步，立體聲聽起來會像指甲刮黑板。

### 4. RDS 數位解構：對抗物理的巔峰
*   **關鍵參數**：
    *   **961-tap 狙擊級濾波器**：在 `rds_final_decoder.py` 中，我們將濾波器拉高到 **961 階**。
    *   **Why？**：RDS 訊號強度極弱（僅佔發射總能量不到 3%）。961 階提供了如手術刀般的頻譜切割力，徹底排除 53kHz 以下立體聲訊號的串擾。
*   **位元同步演算法**：
    *   `np.linspace(0, samples_per_bit, 8)`
    *   **邏輯**：系統會並行模擬 8 個不同的起始相位（Clock Phases），每 1/8 個位元循環一次。
    *   **判斷基準**：哪一個相位能觸發最多的 CRC Syndrome 匹配，那就是真實的時鐘鎖定點。
*   **CRC 與 Syndrome 物理密碼**：
    *   **生成多項式**：`p = 0x5B9` (對應 $x^{10} + x^8 + x^7 + x^5 + x^4 + x^3 + 1$)。
    *   **Offset Words**：`A: 0x3D8, B: 0x3D4, C: 0x25C, D: 0x258`。
    *   **Why？**：RDS 協議沒給前導碼。我們每一位元都在滑動計算這組餘數，當餘數剛好等於這四組魔術數字之一，代表我們這一秒「抓到了」資料框的開頭。
